
# 🌐 Personal Academic Portfolio

### CS381 – Web Development Assignment

A personal academic portfolio website developed as part of the CS381 course at Yanbu Industrial College.

The website introduces my academic background, interests in web development and UI/UX design, and demonstrates my understanding of HTML and CSS through a structured, user-friendly interface.

---

## ✨ Features

- 🏠 Home page with a personal introduction
- 👩‍💻 Profile page presenting personal and academic information
- 📩 Contact page
- 🎨 Custom styling using CSS
- 🖼️ Images and multimedia content
- 📐 Wireframe and design documentation

---

## 🛠️ Technologies Used

- HTML5
- CSS3
- GitHub Pages

---

## 📂 Project Structure

- `index.html` – Home page
